# Decision Trees

This project is intended for educational purposes. A decision tree is a machine learning algorithm used for both classification and regression tasks. 
It breaks down a dataset into smaller subsets while simultaneously developing an associated tree. The final result is a tree with decision nodes and leaf nodes.
A decision node has two or more branches, and a leaf node represents a classification or decision. Entropy is a measure of the uncertainty or randomness in a set of data. 
In the context of decision trees, entropy is used to determine how a dataset should be split to create the most informative and efficient branches. 
The goal is to create subsets of the data that are as pure as possible (i.e., contain data points that all belong to the same class). 

## Decision Trees main algorithm
1) Calculate Entropy of the Dataset
2) Calculate Entropy for Splits
3) Calculate Information Gain
4) Choose the Best Split
